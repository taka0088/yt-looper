# YT LOOPER

YouTube の動画の好きな区間（A点〜B点）を繰り返し再生し、速度を変えて練習するための Web アプリです。
MacBook のブラウザと iPhone の Safari（ホーム画面に追加してアプリとして）で動きます。

## 使い方

1. YouTube の URL を貼り付ける（貼り付けるだけで読み込まれます）
2. 再生しながら「A 今の位置を開始点に」「B 今の位置を終了点に」を押す。±0.1秒ボタンやハンドルのドラッグ（ドラッグ中は位置の時刻が吹き出しで出ます）で微調整。
   カードの時刻をタップすると「1:23.4」のように直接入力もできます（「83.4」「1m23s」も可）。
   細いミニマップは動画全体の位置（クリックで頭出し）、その下の**ルーペ帯**は A–B の前後だけを横幅いっぱいに拡大したもので、ここで A/B の線をドラッグすると 0.1 秒以下の精度で動かせます（キーボードの ← → で 0.1 秒、Shift で 1 秒）
3. 「ループ」を点灯させると A→B を繰り返す
4. 速度は 0.25× 〜 2× のボタンで切り替え
5. 「この区間を保存」で名前を付けて保存。次に同じ動画を開くと最初の区間が自動で復元されます
6. タブ譜を大きく見たいときは、動画の下の「表示」で 標準 / 大きく / 全幅 を切り替え（Mac）、
   「拡大」の ＋ で動画をズームして、動画をドラッグすると見たい位置に寄せられます（Mac・iPhone）。
   Mac ではトラックパッドのピンチ（Ctrl+ホイール）でもズームできます。拡大率と位置は動画ごとに記憶されます
7. 動画右下の □ ボタン（またはキー T）で**シアターモード**。動画が横幅いっぱいになり、LOOPER だけが薄く残ります。Esc か同じボタンで戻ります
8. 停止中は YouTube の「その他の動画」などを隠します。停止中の画面を見たいときはチェックを外してください
9. LOOPER の SEEK 列で ±1 / 5 / 10 / 30 秒の巻き戻し・早送りができます
10. 「再生前に 3 カウント」を ON にすると、PLAY のあと 3・2・1 のカウントダウンをはさんでから音が出ます

## YouTube の表示（タイトル・共有・その他の動画）について

埋め込みプレーヤーは再生開始時とシークのたびに、上端にタイトルバー、下端に共有・「その他の動画」を約3秒表示します。
API では消せないため、このアプリでは iframe を見える枠より上下に大きくし、動画を中央の帯に収めています。
YouTube の表示は上下の黒帯（枠の外）に載るので画面には映りません。
中央に一瞬出る再生/停止アイコン（約0.5秒）だけは位置的に隠せません。

Mac ではキーボードで操作できます：Space（再生/停止）、A / B（今の位置を A点 / B点に）、L（ループ）、Enter（A点へ）、← →（1秒、Shift で5秒）、[ ]（速度）

## アプリ内で検索する（任意）

上の入力欄に曲名などを入れて Enter を押すと、その場で YouTube を検索できます。
これには Google の **YouTube Data API キー**（無料）が必要です。初回の検索時に取り方が画面に出ます：

1. https://console.cloud.google.com/apis/library/youtube.googleapis.com を開いてログイン（プロジェクトがなければ作成）
2. 「YouTube Data API v3」を有効にする
3. 「認証情報」→「認証情報を作成」→「API キー」
4. 表示されたキーをアプリに貼り付けて保存

キーはブラウザ内にだけ保存されます。無料枠は 1 日あたり約 100 回の検索です。

## 起動方法（Mac）

フォルダ内の **「YT LOOPER.app」をダブルクリック**すると、サーバーが起動してブラウザでアプリが開きます。
Dock や「アプリケーション」フォルダにドラッグしておくと便利です。
サーバーは Mac を再起動するまで動き続けます。止めたいときは `stop.sh` を実行します。

初回だけ「開発元を検証できません」と出た場合は、右クリック →「開く」で起動できます。

手動で起動する場合（YouTube の埋め込みプレーヤーは `file://` では動かないので、ローカルサーバーが必要です）：

```bash
cd "/Users/nakaotakayuki/YouTubeルーパー" && python3 serve.py 8765
```

ブラウザで http://localhost:8765 を開きます。

## iPhone で使う

### 方法1：同じ Wi‑Fi の Mac に接続する（手軽）

上のサーバーを Mac で起動したまま、Mac の IP アドレスを調べます。

```bash
ipconfig getifaddr en0
```

iPhone の Safari で `http://<そのIP>:8765` を開き、共有ボタン →「ホーム画面に追加」。
Mac を閉じるとつながらなくなる点に注意。

### 方法2：GitHub Pages などに置く（どこからでも使える）

このフォルダの中身をそのまま静的ホスティング（GitHub Pages / Netlify / Vercel など）にアップロードすれば、
https で配信されるので Service Worker も有効になり、iPhone のホーム画面アプリとして安定して使えます。

## 制約

- **再生速度は YouTube 埋め込みプレーヤーが許可する刻み（0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2）のみ。** 0.6× などの任意の値は API 上設定できません
- 埋め込みを許可していない動画は再生できません（YouTube 側の設定）
- 保存した区間はブラウザごとの localStorage に入るため、Mac と iPhone の間では共有されません

- `manifest.webmanifest` / `icon*.{svg,png}` — ホーム画面追加用
