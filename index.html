    曲名で検索したい場合（API キーの取り方）

    検索には Google の YouTube Data API キーが必要です（無料）。取り方：

    1. Google Cloud Console を開き、Google アカウントでログイン（プロジェクトがなければ「プロジェクトを作成」）
    2. 「YouTube Data API v3」を有効にする
    3. 左メニュー「認証情報」→「認証情報を作成」→「API キー」
    4. 表示されたキーを下に貼り付けて保存

    キーはこのブラウザの中にだけ保存され、YouTube への検索リクエスト以外には使いません。
